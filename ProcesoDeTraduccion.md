# Proceso de Traducción y Reconstrucción Sintáctica (Paso a Paso)

Este documento detalla el proceso filológico intermedio entre el texto griego original y la traducción final. Se expone, para cada párrafo:
1.  **Texto Griego:** Fragmento original.
2.  **Traducción Literal (Palabra a Palabra):** Siguiendo estrictamente el orden de palabras griego (*hyperbaton*), mostrando la estructura "desorganizada" en español.
3.  **Análisis de Reordenamiento y Adiciones:** Justificación gramatical de por qué se mueven las palabras o se añaden nexos/artículos, basado en el `AnalisisMorfologico.md`.
4.  **Traducción Final Ordenada:** El resultado coherente en español.

---

## **Párrafo 1: Introducción**

### **1. Texto Griego**
Περὶ μὲν οὖν τῆς ἐν ἑξαμέτροις μιμητικῆς καὶ περὶ κωμῳδίας ὕστερον ἐροῦμεν· περὶ δὲ τραγῳδίας λέγωμεν ἀναλαβόντες αὐτῆς ἐκ τῶν εἰρημένων τὸν γινόμενον ὅρον τῆς οὐσίας.

### **2. Traducción Literal (Orden Griego)**
"Acerca de / por una parte / pues / la / en / hexámetros / imitativa [arte] / y / acerca de / comedia / luego / hablaremos; / acerca de / por otra parte / tragedia / hablemos / habiendo retomado / de ella / a partir de / las [cosas] / dichas / la / que surge / definición / de la / esencia."

### **3. Análisis de Reordenamiento y Adiciones**
*   **Partículas (*mèn oûn*):** Se agrupan al inicio como conector lógico: "Así pues" o "Pues bien".
*   **Hipérbaton (*tês... mimētikês*):** El griego intercala *en hexamétrois* entre el artículo (*tês*) y el sustantivo (*mimētikês*). En español, debemos unir el sintagma nominal: "la [arte] imitativa en hexámetros" (Poesía épica). Se añade "[arte]" o "imitación" porque *mimētikês* es un adjetivo sustantivado.
*   **Elipsis del sujeto:** *Eroûmen* (hablaremos) contiene el sujeto "nosotros".
*   **Participio (*analabóntes*):** Literalmente "habiendo retomado" (Aoristo). Funciona como un gerundio modal o temporal en la oración principal: "retomando".
*   **Genitivos:** *Autês* (de ella) se coloca adyacente a su regente (*óron* o *ousías*), aunque en griego está separado. Se traduce "su esencia".

### **4. Traducción Final**
"Así pues, acerca de la imitación en hexámetros y de la comedia hablaremos luego; hablemos ahora sobre la tragedia, retomando la definición de su esencia que surge de lo dicho."

## **Párrafo 2: Definición Esencial**

### **1. Texto Griego**
Ἔστιν οὖν τραγῳδία μίμησις πράξεως σπουδαίας καὶ τελείας μέγεθος ἐχούσης, ἡδυσμένῳ λόγῳ χωρὶς ἑκάστῳ τῶν εἰδῶν ἐν τοῖς μορίοις, δρώντων καὶ οὐ δι ̓ ἀπαγγελίας, δι ̓ ἐλέου καὶ φόβου περαίνουσα τὴν τῶν τοιούτων παθημάτων κάθαρσιν.

### **2. Traducción Literal (Orden Griego)**
"Es / pues / tragedia / imitación / de acción / noble / y / completa / magnitud / que tiene, / con sazonado / lenguaje / separadamente / para cada una / de las / especies / en / las / partes, / de actuantes / y / no / mediante / relato, / a través de / compasión / y / temor / llevando a cabo / la / de las / tales / afecciones / catarsis."

### **3. Análisis de Reordenamiento y Adiciones**
*   **Concordancia (*práxeōs spoudaías...*):** El bloque de genitivos (de acción noble y completa) se mantiene unido.
*   **Participio atributivo (*echousēs*):** Literalment "teniente". Se transforma en oración de relativo: "que tiene magnitud".
*   **Dativo instrumental (*hēdysménō lógō*):** Se añade la preposición "con" para marcar el instrumento: "con lenguaje sazonado".
*   **Construcción distributiva (*chorìs hekástō...*):** Literalmente "separadamente para cada uno de los tipos". Se reordena para fluidez: "separada cada una de las especies [de aderezos] en las partes".
*   **Genitivo absoluto/Agente (*dróntōn*):** Literalmente "de actuantes". Aristóteles opone esto a *di' apangelías* (mediante relato). Se traduce explicativamente: "[imitación] de quienes actúan".
*   **Sintagma de la Catarsis (*tēn... kátharsin*):** El griego encierra *tôn toioútōn pathemátōn* dentro del artículo y el sustantivo (*tēn... kátharsin*). En español desplegamos el genitivo: "la purificación **de** tales pasiones".

### **4. Traducción Final**
"Es, pues, la tragedia imitación de una acción noble y completa, que tiene magnitud; con lenguaje adornado, separado cada uno de las especies en las partes; de quienes actúan y no mediante relato; que a través de la compasión y el temor lleva a cabo la purificación (catarsis) de tales pasiones."

## **Párrafo 3: Explicación de los Medios (Lenguaje)**

### **1. Texto Griego**
Λέγω δὲ ἡδυσμένον μὲν λόγον τὸν ἔχοντα ῥυθμὸν καὶ ἁρμονίαν [καὶ μέλος], τὸ δὲ χωρὶς τοῖς εἴδεσι τὸ διὰ μέτρων ἔνια μόνον περαίνεσθαι καὶ πάλιν ἕτερα διὰ μέλους.

### **2. Traducción Literal (Orden Griego)**
"Digo / y / sazonado / por una parte / lenguaje / el / que tiene / ritmo / y / armonía / [y canto], / lo [que es] / por otra parte / separadamente / para las / especies / el / mediante / metros / unas cosas / solo / llevarse a cabo / y / de nuevo / otras cosas / mediante / canto."

### **3. Análisis de Reordenamiento y Adiciones**
*   **Definición explícita:** *Légō* se traduce "Llamo" o "Entiendo por".
*   **Articulación (*tò dè chorìs...*):** Una construcción compleja sustantivada por el artículo neutro *tò*. Literalmente "lo [de] separadamente". Se explica: "y [llamo] 'por separado con las especies' al hecho de que...".
*   **Infinitivo sustantivado (*peraínesthai*):** El infinitivo pasivo "llevarse a cabo" depende del artículo *tò*. Se traduce como una oración completiva: "al hecho de que algunas cosas se efectúan...".
*   **Suplementos:** Se añade "[llamo]" en la segunda cláusula por paralelismo con el primer *Légō*.

### **4. Traducción Final**
"Llamo lenguaje sazonado al que tiene ritmo, armonía y canto; y [llamo] 'por separado con las especies' al hecho de que algunas cosas se llevan a cabo solo mediante versos y otras, a su vez, mediante el canto."

## **Párrafo 4: Deducción de las Partes (Espectáculo y Actores)**

### **1. Texto Griego**
Ἔπεὶ δὲ πράττοντες ποιοῦνται τὴν μίμησιν, πρῶτον μὲν ἐξ ἀνάγκης ἂν εἴη τι μόριον τραγῳδίας ὁ τῆς ὄψεως κόσμος· εἶτα μελοποιία καὶ λέξις...

### **2. Traducción Literal (Orden Griego)**
"Puesto que / y / actuando / se hacen [para sí] / la / imitación, / primero / por una parte / por / necesidad / podría / ser / alguna / parte / de tragedia / el / de la / vista / adorno; / luego / melopeya / y / elocución..."

### **3. Análisis de Reordenamiento y Adiciones**
*   **Participio circunstancial (*práttontes*):** "Actuando" o "como son agentes los que...". Se opta por "actuando" modificando al sujeto.
*   **Voz Media (*poioûntai*):** "Realizan" (construyen).
*   ***Ex anánkēs*:** Frase preposicional "por necesidad" -> adverbio "necesariamente".
*   ***Ho tês ópseōs kósmos*:** Hipérbaton. "El de la vista adorno" -> "La decoración del espectáculo" (*ópsis* se traduce técnicamente como espectáculo).

### **4. Traducción Final**
"Puesto que realizan la representación actuando, primero sería necesariamente una parte de la tragedia la decoración del espectáculo; luego la melopeya y la elocución, pues en estos [medios] realizan la imitación."

## **Párrafo 5: Deducción Lógica (Mito, Carácter, Pensamiento)**

### **1. Texto Griego**
Ἐπεὶ δὲ πράξεώς ἐστι μίμησις, πράττεται δὲ ὑπὸ τινῶν πραττόντων, οὓς ἀνάγκη ποιούς τινας εἶναι κατά τε τὸ ἦθος καὶ τὴν διάνοιαν... ἔστιν δὲ τῆς μὲν πράξεως ὁ μῦθος ἡ μίμησις...

### **2. Traducción Literal (Orden Griego)**
"Puesto que / y / de acción / es / imitación, / es actuada / y / por / algunos / actuantes, / a los cuales / necesidad / de cierta cualidad / unos / ser / según / tanto / el / carácter / y / el / pensamiento... / es / y / de la / por una parte / acción / el / mito / la / imitación..."

### **3. Análisis de Reordenamiento y Adiciones**
*   **Pasiva e indefinidos:** *Práttetai hypò tinôn* ("es actuada por algunos").
*   **Acusativo de relación (*poioús tinas*):** "Ser de cierta cualidad". Aristóteles usa el indefinido *poioús* (cualesquiera/tales) para indicar cualidad moral.
*   **Definición Cruzada:** "Del acción el mito la imitación". Se reordena: "El mito es la imitación de la acción".
*   **Precisión terminológica:** *Mûthos* se aclara como [trama] para el lector moderno, aunque se mantiene "mito" por rigor.

### **4. Traducción Final**
"Y puesto que es imitación de una acción, y es actuada por algunos que actúan, a quienes es necesidad ser de cierta cualidad según el carácter y el pensamiento... el mito [trama] es la imitación de la acción;"

## **Párrafo 6: La Supremacía de la Acción (El Fin)**

### **1. Texto Griego**
Μέγιστον δὲ τούτων ἐστὶν ἡ τῶν πραγμάτων σύστασις. Ἡ γὰρ τραγῳδία μίμησίς ἐστιν οὐκ ἀνθρώπων ἀλλὰ πράξεων καὶ βίου...

### **2. Traducción Literal (Orden Griego)**
"Lo más grande / y / de estas [cosas] / es / la / de los / hechos / estructuración. / La / pues / tragedia / imitación / es / no / de hombres / sino / de acciones / y / de vida..."

### **3. Análisis de Reordenamiento y Adiciones**
*   **Superlativo neutro (*Mégiston*):** "Lo más importante" o "Lo máximo".
*   **Genitivo subjetivo (*tôn pragmátôn*):** "De los hechos/cosas". Se refiere a los eventos de la trama.
*   **Sintaxis negativa:** "No de hombres... sino de acciones". Se mantiene el orden para énfasis retórico.

### **4. Traducción Final**
"De estos elementos, el más importante es la estructuración de los hechos. Pues la tragedia no es imitación de hombres, sino de acciones y de la vida..."

## **Párrafo 7: Definición de Carácter y Pensamiento**

### **1. Texto Griego**
Ἔστιν δὲ ἦθος μὲν τὸ τοιοῦτον ὃ δηλοῖ τὴν προαίρεσιν... διάνοια δὲ ἐν οἷς ἀποδεικνύουσί τι ὡς ἔστιν ἢ ὡς οὐκ ἔστιν...

### **2. Traducción Literal (Orden Griego)**
"Es / y / carácter / por una parte / lo / tal / que / manifiesta / la / elección... / pensamiento / y / en / los [que] / demuestran / algo / como / es / o / como / no / es..."

### **3. Análisis de Reordenamiento y Adiciones**
*   ***Tò toioûton hò*:** "Aquello tal que..." o "Tal cosa que...". Define la naturaleza genérica del carácter.
*   ***Proaíresin*:** Término técnico fundamental ("elección deliberada" o "propósito moral"). Se traduce "elección".
*   **Elipsis en Diánoia:** "[Hay] pensamiento en los que...". Se suple el verbo "hay/existe" para dar sentido a la frase preposicional *en hoîs*.

### **4. Traducción Final**
"Es carácter tal cosa que manifiesta la elección... y pensamiento [hay] en los que demuestran que algo es o no es..."
